# textbook-rag 模块全景需求

## 业务场景

基于教材的 RAG 问答系统，不同角色（学生/老师/研究员）使用不同 prompt，需要覆盖从文档处理到用户交互的完整链路。

## 系统架构

```
 ┌─────────────────── 数据层 ───────────────────┐
 │  Document → Chunking → Embedding → Knowledge │
 └──────────────────────┬────────────────────────┘
                        ↓
 ┌─────────────────── 检索层 ───────────────────┐
 │  Auth → Question → Retrieval → Citation      │
 └──────────────────────┬────────────────────────┘
                        ↓
 ┌─────────────────── 生成层 ───────────────────┐
 │  Prompt → LLM → Cache                       │
 └──────────────────────┬────────────────────────┘
                        ↓
 ┌─────────────────── 质量层 ───────────────────┐
 │  Evaluation → Report → Chart                 │
 └──────────────────────────────────────────────┘
```

## 数据层

### 1. Document — 文档处理

| 功能 | 说明 | 状态 |
|------|------|------|
| PDF 解析 | 版面分析、文字提取 | ✅ MinerU |
| OCR | 扫描件/图片文字识别 | ✅ MinerU |
| 表格提取 | 结构化提取表格数据 | ✅ MinerU |
| 多格式支持 | Word、PPT、HTML、Markdown | ⚠️ 部分支持 |

### 2. Chunking — 文本分块

| 功能 | 说明 | 状态 |
|------|------|------|
| 固定分块 | 按字符数/token 数切分 | ✅ 已有 |
| 语义分块 | 按语义边界切分 | ❌ 需建 |
| 文档感知分块 | 按标题/段落/章节切分 | ⚠️ 基础版 |
| 分块评估 | 评估分块质量（重叠度/完整性） | ❌ 需建 |

### 3. Embedding — 向量化

| 功能 | 说明 | 状态 |
|------|------|------|
| 模型管理 | 注册多个 embedding 模型 | ⚠️ 基础版 |
| Batch 处理 | 大批量文档高效向量化 | ⚠️ 基础版 |
| 模型对比 | 不同 embedding 模型效果对比 | ❌ 需建 |
| 增量更新 | 只处理新增/修改的文档 | ❌ 需建 |

### 4. Knowledge — 知识库管理

| 功能 | 说明 | 状态 |
|------|------|------|
| 文档上传/管理 | 上传、删除、分类 | ⚠️ 基础版 |
| 元数据管理 | 科目、年级、章节标签 | ❌ 需建 |
| 知识图谱 | 概念关联、跨文档链接 | ❌ 需建 |
| 数据统计 | 文档数、chunk 数、覆盖率 | ❌ 需建 |

## 检索层

### 5. Auth — 用户/角色管理（Payload CMS 已内置）

| 功能 | 说明 | 状态 |
|------|------|------|
| 用户认证 | 登录/注册 | ✅ Payload 内置 |
| 角色管理 | 学生/老师/研究员/管理员 | ✅ Payload Access Control |
| 权限控制 | 不同角色访问不同知识库 | ✅ Payload Field-level Access |

### 6. Question — 问题处理

| 功能 | 说明 | 状态 |
|------|------|------|
| 问题生成 | 从教材自动生成测试题 | ✅ Ragas Testset Gen |
| 意图识别 | 判断问题类型（事实/推理/比较） | ❌ 需建 |
| 问题改写 | Query rewriting / expansion | ❌ 需建 |
| 多轮对话 | 上下文跟踪、指代消解 | ❌ 需建 |

### 7. Retrieval — 检索策略

| 功能 | 说明 | 状态 |
|------|------|------|
| 向量检索 | 基础语义搜索 | ✅ 已有 |
| 关键词检索 | BM25 全文搜索 | ⚠️ 基础版 |
| 混合检索 | 向量 + 关键词融合 | ❌ 需建 |
| 重排序 | Reranker 对结果二次排序 | ❌ 需建 |
| 策略切换 | 不同问题类型用不同检索策略 | ❌ 需建 |

### 8. Citation — 溯源定位

| 功能 | 说明 | 状态 |
|------|------|------|
| 页码定位 | 定位到原始 PDF 页码 | ⚠️ 基础版 |
| 段落高亮 | 在原文中高亮引用内容 | ⚠️ 基础版（痛点） |

## 约束条件

- 必须支持本地 LLM（Ollama / vLLM）
- 易于扩展（模块化架构）
- 基于已有框架（Payload CMS + Next.js + FastAPI）
- 教育场景优先（教材、教学、考试）
