# 许可证兼容性指南

## 许可证分类

### ✅ 商业友好 (可直接商用)

| 许可证 | 特点 | 使用建议 |
|--------|------|----------|
| **MIT** | 最宽松，几乎没有限制 | ✅ 首选 |
| **Apache-2.0** | 允许专利授权 | ✅ 首选 |
| **BSD-3-Clause** | 允许闭源使用 | ✅ 推荐 |
| **BSD-2-Clause** | 非常宽松 | ✅ 推荐 |
| **ISC** | 类似 MIT | ✅ 推荐 |
| **Unlicense** | 放弃所有权利 | ✅ 完全无限制 |
| **CC0** | 公有领域 | ✅ 完全无限制 |

### ⚠️ 需注意 (有限使用)

| 许可证 | 特点 | 使用建议 |
|--------|------|----------|
| **LGPL-2.1/3.0** | 允许动态链接 | ⚠️ 需确认链接方式 |
| **MPL-2.0** | 允许闭源，但修改需开源 | ⚠️ 记录修改内容 |
| **CDDL-1.0** | 类似 MPL | ⚠️ 同上 |
| **EPL-2.0** | 允许闭源插件 | ⚠️ 插件除外 |

### 🚫 传染性许可证 (需谨慎)

| 许可证 | 特点 | 使用建议 |
|--------|------|----------|
| **GPL-2.0** | 修改必须开源 | 🚫 商业项目慎用 |
| **GPL-3.0** | 链接代码必须开源 | 🚫 商业项目慎用 |
| **AGPL-3.0** | 网络使用也必须开源 | 🚫 避免使用 |
| **SSPL-1.0** | 数据库服务也需开源 | 🚫 避免使用 |
| **Commons Clause** | 限制商业服务 | ⚠️ 仔细阅读 |

## 许可证兼容性矩阵

```
来源许可证 →     MIT   Apache   GPL    LGPL   AGPL
目标许可证
─────────────────────────────────────────────────
MIT              ✅    ✅       ⚠️     ⚠️     🚫
Apache-2.0       ✅    ✅       ⚠️     ⚠️     🚫
GPL-3.0          ⚠️    ⚠️      ⚠️     ⚠️     🚫
LGPL-2.1         ✅    ✅       ⚠️     ⚠️     🚫

✅ = 兼容 | ⚠️ = 有条件 | 🚫 = 不兼容
```

## 快速决策规则

1. **商业项目** → 只选 MIT/Apache/BSD
2. **开源项目** → 可以考虑 LGPL
3. **SaaS服务** → 避开 AGPL/GPL
4. **插件系统** → 考虑 MPL/EPL
